# 🏥 Hospital Readmissions Prediction

## 📌 Overview

This project focuses on predicting hospital readmissions using machine learning techniques. The goal is to identify patients at high risk of being readmitted within 30 days after discharge, enabling better healthcare planning and improved patient outcomes.

The system was built as part of a machine learning pipeline including data preprocessing, feature engineering, model training, and evaluation.

---

## 🎯 Problem Statement

Hospital readmissions are a major challenge in healthcare systems, increasing operational costs and indicating potential gaps in patient care. This project aims to build a predictive model that can classify whether a patient is likely to be readmitted after discharge based on historical clinical data.

---

## ⚙️ Project Pipeline

### 1. Data Preprocessing

* Handling missing values
* Encoding categorical features
* Feature scaling and normalization
* Removing irrelevant or high-missing-rate columns

### 2. Feature Engineering

* Creation of meaningful features from raw clinical data
* Transformation of diagnosis and medical history variables
* Improving feature representation for better model performance

### 3. Modeling

The following machine learning models were explored:

* Logistic Regression
* Decision Trees
* Random Forest
* Gradient Boosting Models
* Ensemble Methods

### 4. Evaluation

Models were evaluated using:

* Accuracy
* Precision
* Recall
* F1 Score
* ROC-AUC Score

---

## 📊 Results

The final model achieved strong predictive performance in identifying high-risk patients, demonstrating the effectiveness of machine learning in healthcare risk prediction tasks.
